How to install

  1. Tap Download for Android. If Chrome asks whether to keep the file, tap Download anyway.
  2. When the download finishes, tap Open to install.
  3. If your phone asks, allow Chrome to install apps: tap Settings, turn on Allow from this source, then go back.
  4. If Google Play Protect shows a warning, tap More details, then Install anyway. You see this because the app isn't in the Play Store yet.
  5. Open Heimish Discount and sign up — your invite code is already filled in. If it isn't, paste it (it's on your clipboard) or type it in the Invite code box.
