SMS Opt-In Evidence

This page publicly documents how end users consent to receive Heimish Discount SMS messages.

Required SMS disclosures

By texting START to 845-470-4411, or by checking the SMS consent box on the Heimish Discount website, you agree to receive SMS messages from Heimish Discount for ride requests, ride updates, and customer support. Message frequency varies. Message and data rates may apply. Text HELP for help. Text STOP to unsubscribe. SMS consent is not required as a condition of purchase.

Terms: https://heimishdiscount.com/terms-and-conditions/
Privacy Policy: https://heimishdiscount.com/privacy-policy/

1. SMS keyword opt-in

  1. End users see local advertising or marketing material for Heimish Discount.
  2. The ad tells users to text START to 845-470-4411.
  3. The ad includes the required consent language, message frequency, message and data rates, HELP instructions, STOP unsubscribe instructions, Terms, and Privacy Policy.
  4. The user actively sends START to 845-470-4411.
  5. The user receives an opt-in confirmation message.

2. Website opt-in

  1. End users visit https://heimishdiscount.com/#sms, which opens the SMS signup form directly.
  2. Users can also open the same form from the homepage by clicking "Ride Heimish by text."
  3. The user enters a phone number.
  4. The SMS consent checkbox is unchecked by default.
  5. The SMS consent checkbox is optional and separate from Terms and Privacy acceptance. Users may continue without checking the SMS consent box.
  6. If the user wants to receive SMS ride messages, the user actively checks the optional SMS consent box before continuing.
