How to install

  1. Tap Download for Android. If Chrome asks whether to keep the file, tap Download anyway.
  2. When the download finishes, tap Open.
  3. If your phone asks, allow Chrome to install apps: tap Settings, turn on Allow from this source, then go back.
  4. If Google Play Protect shows a warning, tap More details, then Install anyway. You see this because the beta isn't in the Play Store yet.
  5. Open Heimish Discount and sign in with your phone number.

Updates

Updates install themselves. A new version downloads the next time you open the app and shows up the time after that.

To get it right away, close the app completely and open it again.

Testing payments

The beta uses test payments, so no real money is charged. Real cards won't work.

To test a card, use 4242 4242 4242 4242 with any future date and any 3-digit code. You can also choose cash.
